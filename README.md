# Your Financial Advisor

**Understand your budget. Set priorities. Plan your financial goals.**

Your Financial Advisor is an AI agent profile designed to support personal financial planning through clear analysis and practical recommendations. It helps users review their income, expenses, and financial goals to make more informed decisions.

## Key Features

- **Budget analysis:** Review income and spending to identify areas for improvement.
- **Financial planning:** Organize priorities around existing commitments and goals.
- **Savings guidance:** Explore practical steps toward a savings target.
- **Structured recommendations:** Receive an overview, analysis, proposed plan, and relevant considerations.

## Getting Started

This profile runs in Hermes with a configured model provider.

1. Create a profile in Hermes.
2. Add the instructions from [SOUL.md](SOUL.md) to the profile’s personality configuration.
3. Select a model and start a new conversation.

To begin, describe your monthly income, main expense categories, existing commitments, and financial goals using summary amounts.

## Example Requests

> Help me build a monthly budget around my income and essential expenses.

> Review my spending categories and suggest opportunities to save.

> Help me plan toward a savings goal within a specific timeframe.

## Responsible Use

Responses may contain errors and should be reviewed before making financial decisions. Do not share passwords, bank card details, or verification codes.
