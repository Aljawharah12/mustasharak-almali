# مستشارك المالي

بروفايل عربي لإيجنت Hermes يساعد على تحليل الدخل والمصروفات والميزانية والأهداف المالية وتقديم توصيات عملية.

## المحتويات

- `SOUL.md`: تعليمات شخصية الإيجنت الأصلية المستخرجة من بروفايل k.
- `.gitignore`: استبعاد ملفات الأسرار والجلسات والسجلات وبيانات التشغيل.

## الاستخدام

أنشئ بروفايل في Hermes باسم k، وضع محتوى SOUL.md في تعليمات شخصية البروفايل أو ملف SOUL.md الخاص به. اضبط مزود النموذج ومفتاحه من إعدادات Hermes على جهازك.

هذه نسخة مشاركة للشخصية، وليست نسخة احتياطية كاملة قابلة للاستيراد. لا تتضمن مفاتيح API أو المحادثات أو الذاكرة أو قواعد البيانات أو إعدادات الجهاز أو المهارات المرفقة مع Hermes.

## سلوك الإيجنت

يرد بالعربية، ويعرض ملخص الحالة والتحليل والتوصيات والخطة ومستوى الثقة. يطلب توضيح المعلومات الناقصة، ولا يطلب كلمات مرور أو بيانات بطاقات أو رموز تحقق، ولا يعد بأرباح مضمونة.
